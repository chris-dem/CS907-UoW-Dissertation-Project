The current section focuses on how we can extend our reductions
to \textit{SourceOrExcess}. In the previous sections,
we gave an overview on how we can go from an \textit{EndOfLine} problem
to a topological problem. In the current section, we show how we can extend the idea
for the \textit{SourceOrExcess} problem. We hope by parsimoniously reducing the
\textit{SourceOrExcess} problem to a topological problem, it will lead
to future reductions to the \textit{PureCircuit}.


\subsubsection{Topological representations}


\subsubsection{Topological Parsimonious Reduction}

% TODO: Fix references
In section {}, when talking about the \textit{StrongSperner} problem,
we observed how coloured subspaces may lead to many duplicated solutions.
Here, we are slightly modifying the definition of \textit{3D-StrongSperner}
in order to take advantage of that. We will then show how the above modification
can lead to parsimonious reductions.


\begin{definitionbox}{\textit{3D-CountingSS} problem definition}{3d-counting-ss}
    \textbf{Input}: A hazard-free colouring circuit $\lambda: (\{0,1\}^k)^3 \to \{-1,+1\}^3$ which
    follows the boundary conditions of the \textit{StrongSperner} problem as explained in \ref{def:strong-sperner}.

    \textbf{Output}: A coordinate $p= (ib_1, jb_2, kb_3) \in (\{0,1, \bot\}^k)^3$
    such that $\lambda(p) = \bot^3$ for some $b \in \{0,1, \bot\}^3$. To avoid double counting, accept only solutions such that
    $$
        \max \{(ib_1, jb_2, kb_3) \mid b \in \{0,\bot\}^3: \lambda(ib_1, jb_2, kb_3) = \bot^3\}
    $$
    Where the $\max$ follows the information ordering of \textit{Kleene logic}.
\end{definitionbox}




% TODO: Add interpretation with directional values
The above idea is a natural extension of the \textit{StrongSperner} interpretation, where
its labelling represents the direction of a continuous function. If a face
of a cube is panchromatic, then that implies that there has to be a fixed point somewhere,
as seen in the figure \ref{fig:chap-3:panc-edge}. If an edge were to be panchromatic,
then that means that a fixed point could lie on the edge. If we were treating this as a
fixed point problem instead of a colouring one, it would make sense to argue that we have one solution.
We abuse this notion to count only the smallest possible subspace that contains the solution, for example
in \textit{2D}, only count the edge that yield the labelling instead of all the cubes that contains the edge.

To prove \textbf{PPAD}-completeness, we know that the above problem can be reduced to \textit{3D-StrongSperner},
although the reduction will not be parsimonious. We now show the main result of our section:

\begin{theorembox}{Parsimonious reduction from $\textit{SourceOrExcess}(2,1)$}{}
    $$
        \textbf{\#PPAD}(\textit{SourceOrExcess}(2,1)) \subseteq
        \textbf{\#PPAD}(\textit{3D-CountingSS})
    $$
\end{theorembox}

Given a \textit{SourceOrExcess} input, we apply the following series of transformations:

\begin{enumerate}
    \item \textbf{Circuit Augmentation}: Eliminate all excess nodes such that the graphs only contain sources, sinks, isolated nodes, line nodes
          and double sinks.
    \item \textbf{Planar Embedding}: Embed the graph in a 3D coordinate space.
    \item \textbf{Topological colouring}: Apply colouring rules that follow the \textit{3D-CountingSS} rules such that
          our panchromatic squares contains \textit{SourceOrExcess} solutions.
\end{enumerate}

\paragraph*{Circuit Augmentation}
We attempt to eliminate all excess nodes, meaning nodes with degree $(2,1)$ by separating
one of the lines as shown in the figure \ref{fig:source-or-excess-trans}.
Moreover for double sinks, we enforce that the MSB value of the bit-string for one of the two values is one.
We can observe that these modifications can be done in polynomial time since they only require to analyse
the local neighbouring of nodes, and they preserve the number of solutions.
We emphasize that if a node is not incident to double sink, then it will act as an isolated node.

\paragraph*{Planar Transformation}

We will propose a similar transformation to the \ref{par:chap-2:planar-graph-embedding}
to encode a 2D representation of the above graph.
Given $n$, we create a 2D space $B_{n}$ such that
$$
    V_{n}  \triangleq  \Big\{ p \in \mathbb{Z}^2 \mid 0 \leq p_{1} \leq 6n^2, 0 \leq p_{2} \leq 12n + 6 \Big\}
$$
We are essentially increasing the dimensions of our cube so we can increase the distance between points.
For every $i \in \{ 0,1 \}^{n+1}$, vertex $i$ represents point $(0,12i)$
Like in the original definition we also create paths between $E_{ij}$
but we for the double sinks we create a different path.
More accurately, $\forall i,j \in E_{n}$  such that $i^{n+1} = 0$, create path
\begin{align*}
    \mathbf{p}^1 & = (0, 12i)                                                                          \\
    \mathbf{p}^2 & = (6n(ni + j), 12i)                                                                 \\
    \mathbf{p}^3 & = (6n(ni + j), 12j + 6)                                                             \\
    \mathbf{p}^4 & = (0, 12j + 6)                                                                      \\
    \mathbf{p}^5 & = (0, 12j)                                                                          \\
    E_{ij}       & \triangleq E(\mathbf{p}^1\mathbf{p}^2) \cup \dots  \cup E(\mathbf{p}^4\mathbf{p}^5)
\end{align*}
If $j$ is a double sink, attach a small tail:
\begin{align*}
    \mathbf{p}^6 & = (3, 12j)                             \\
    E_{ij}'      & \triangleq E(\mathbf{p}^5\mathbf{p}^6)
\end{align*}
If $i^{n+1}=1$, then we create path
\begin{align*}
    \mathbf{p}^1 & = (0,12i)                                                                                                \\
    \mathbf{p}^2 & = (6n(ni + j), 12i)                                                                                      \\
    \mathbf{p}^3 & = (6n(ni + j), 12j)                                                                                      \\
    \mathbf{p}^4 & = (3, 12j)                                                                                               \\
    E_{ij}       & \triangleq E(\mathbf{p}^1\mathbf{p}^2) \cup E(\mathbf{p}^3\mathbf{p}^4) \cup E(\mathbf{p}^3\mathbf{p}^4)
\end{align*}

In the original problem, we argued that for every node, we have I/O lines that denote the input output nodes.
If a node has in-degree of $2$, then there must exist a node of in-degree $2$ out-degree $1$ as seen in
the figure {}. %TODO Add figure for visualisation
This would make it computationally difficult to differentiate between double sinks
as a line would be exponentially long and for each double sink node, and we would end up double counting solutions.
By removing excess nodes, we only have to focus on double sinks. Since there is no output line in a double sink,
we take advantage of that by sending one input from the traditional input line, and the other from the output line.

We can use similar arguments as in the original proof, to argue that:
$\forall v \in V: \textit{degree}(v) \in \{(0,1),(1,0), (1,1), (2,2), (2,0)\}$.
We can observe that, if we do not have any double sinks, our graph follows the original transformation
where only 4 out of the 5 possible degrees are possible. For the $(2,0)$ case, using
figure as reference \ref{fig:chap-2:edge-rleaf}, it suffices to observe what happends in the double
sink case. We can observe that the tail of the $E'_{ij}$ path finishes
at $(3, 12j )$ . The smallest possible height for a transition line % TODO: define what transmission line is or add a figure
would be at a height of $(6n(ni+j))$, which means the smallest possible height
between two nodes is $6$. Meaning all nodes at $(3, 12j)$ do not interect any other path
other than their double sink counterparts. This concludes our argument.

We follow the same construction for the $E^2_n$ and apply the same removal transformation.
The resulting graph is the same as in the traditional \textit{RLeafD} problem but with the addition of double sinks.


\paragraph*{Topological colouring}

This section we show how to colour our circuit to on a \textit{3D-CountingSS} instance.
First we apply the transformation $\mathcal{F}$ to go from a \textit{2D} space into a \textit{3D}, where
\begin{gather*}
    B_n \triangleq \big\{ \mathbf{p} \in \mathbb{N}^3 \mid
    p_1 \leq 36n^2 + 6,
    p_2 \leq 78n + 42,
    p_3 \leq 6,
    \big\} \\
    \mathcal{F} : V_n \to B_n \\
    \forall \mathbf{p} \in V_n: \mathcal{F}(\mathbf{p}) \triangleq
    \begin{pmatrix}
        6 \cdot p_1 + 6 \\
        6 \cdot p_2 + 6 \\
        0               \\
    \end{pmatrix}
\end{gather*} %TODO: Careful about edges

% In addition, like in the original transformation, we add
% edges \(E((0,0,0), (0,6,0)) \cup E((0,6,0), (6,6,0))\).
This mapping essentially re-creates the
\textit{RLeafD} problem in a 3D space, since we are neglecting the 3rd dimension for the most part.
Like in the original transformation, we can decompose our graph into paths, cycles where $(P_i)_{i \in [m]}$.
By using $\mathcal{F}$, every $P_i$ is mapped to a set $I(P_i) \subset B_{n}$, such that
\begin{gather*}
    P = (\mathbf{u}^1, ..., \mathbf{u}^t), \text{if } P \text{ is a cycle } \mathbf{u}^1 = \mathbf{u^t} \\
    I(P) \triangleq \bigcup_{i \in [t- 1]} I(\mathbf{u}^{t-1}, \mathbf{u}^t)
\end{gather*}

For double sinks, we can treat them as two paths that lead to a point, we can therefore decompose double sinks
as $I(P_i) \cup I(P_j) \cup \{\mathbf{m}^{ij}\}$, where $\mathbf{m}^{ij}$ will be denoted as the meet point of the
two paths.

Our shielding notion for this tranformation will work follows.
We again define set points around each line $O(P)$ as such that
\begin{gather*}
    O(P) \triangleq \Big\{\mathbf{p} \in B_{n}
    \setminus I(P) \mid  \exists \mathbf{p}' \in I(P): \|p - p'\|_{\infty} = 1\Big\} \\
    \forall b \{0,1\}: O^b(P) \triangleq \{\mathbf{p} \in O(P) \mid p_3 = b\}
\end{gather*}


If $P$ is a simple path, then we can decompose into $\{\textbf{s}_p, \textbf{e}_p\} \cup L^0(P) \cup R^0(P)$
such that $\textbf{s}_p = \mathcal{F}(\mathbf{u^1}) + \Delta + \Delta^\perp$ and
$\textbf{e}_p = \mathcal{F}(\mathbf{u^t}) + \overline{\Delta} + \overline{\Delta}^\perp$
where: $\Delta = (\mathbf{u}^1 - \mathbf{u}^2), \overline{\Delta} = (\mathbf{u}^{t} - \mathbf{u}^{t-1})$
and $\mathbf{x}^{\perp}$ denotes the perpendicular vector when rotated by $90^\circ$ anticlockwise across the $xy$ plane.
For simple paths and cycles, the decomposition into $L$ and $R$ sets works the same, with the core difference being that
we have two sets of points, one for $z = 0$ and the other for $z = 1$.
For double sinks, assume that paths $P^1, P_2$  intresect at some pont $\mathbf{m}^{ij}$.
We apply the following partition starting from $\mathbf{s}_{P^1}$
\begin{align*}
    O^0(P_i \oplus P_j) & = \{\mathbf{s}_{P^1},\mathbf{u}^1_1, \mathbf{u}^1_2,..., \mathbf{u}^1_k,\mathbf{e}_{P^1}\} \text{ Left of first path up to interection point} \\
                        & \cup \{\mathbf{r}^2_1,\mathbf{r}^2_2, ...,\mathbf{r}^2_k ,\mathbf{s}_{P_2}\} \text{ Right of path 2}                                          \\
                        & \cup \{\mathbf{u}^2_1,\mathbf{u}^2_2, ...,\mathbf{u}^2_k ,\mathbf{e}_{P_2}\} \text{ Left of path 2 up to interection}                         \\
                        & \cup \{\mathbf{r}^1_1,\mathbf{r}^1_2, ...,\mathbf{r}^1_k ,\mathbf{s}_{P_2}\} \text{ Right of path 1}                                          \\
\end{align*}
We ensure that $\mathbf{e}^1, \mathbf{e}^2, \mathbf{m}^{ij}$ are on the same $x$-coord or $y$-coordinate.
The same sets can be done for $O^1(P_i \oplus P_j)$.
We now propose our colouring circuit $\mathcal(M)$ such that
$$
    \mathcal{M}(\mathbf{p}) \triangleq \begin{cases}
        (+,+, (-1)^{p_3})   & \text{if } \exists i, \mathbf{p} \in I(P_i) \vee  \mathbf{p} \in \{(0,0,0 ), (0,0,1)\} \\
        (-, +, (-1)^{p_3})  & \text{if } \exists i, \mathbf{p} \in R(P_i)                                            \\
        (+, -, (-1)^{p_3})  & \text{if } \exists i, \mathbf{p} \in L(P_i)                                            \\
        (-, -, (-1)^{p_3})  & \text{if } \exists ij, \mathbf{p} = \mathbf{m}^{ij}                                    \\
        (-, -,  (-1)^{p_3}) & \text{otherwise}
    \end{cases}
$$

\paragraph*{Correctness proof}
We now prove that our reduction is correct.
We use figure \ref{fig:chap-3:simple-line-example} and assume that path $\mathbf{p}^t, \mathbf{p}^{t+1}$
is in the middle of some line. The red cube will not be panchromatic as $y$-coordinate is $+$ on all corners
and vice versa for the blue cube on the $x$-coordinate. In addition we can observe that the brown cubes surrounding
each face will also not result in a panchromatic cube as: for the brown cube on the left of red will be $-$ on all $y$
coordinates, with the same argument for blue. And for the brown cubs on top, we can observe that $z$-coordinate will be $-$
on all points. Therefore points in between lines or cycles will not result in solutions.

\paragraph{Future Directions}
From the previous section we observed how to reduce \textit{SourceOrExcess}$(2,1)$ to a topological problem.
Just like in the \textit{EndOfLine} problem, we found it essential to reduce it to a \textit{StrongSperner} problem
with polynomial sides and very high dimensionality. We believe that one can abuse the \textit{Snake Embedding} methodology
that we proposed earlier. Indeed one can observe that with correct foldings, the $n$-dimensionsal
space will contain a $n-2$ panchromatic subspace. There are two main questions that need to be resolved:
\begin{enumerate}
    \item Will the number of solutions between foldings?
    \item Is there a natural way to define \textit{Counting-SS}? Like previously, when the
    number of dimensions can vary between instances, by corollary \ref{col:k-bit-haz}, we observed
    that the size of the circuit will explode exponentially, by current literature assumptions. 
\end{enumerate}
More interestingly, in later sections we make references of $\alpha-\textit{SUnbalanced}(\Delta_i, \Delta_o)$
and how they can affect the counting nature of each other. Like we mentioned previously, for
\textit{2D-StrongSperner} and \textit{1-MC}, we cannot guarantee parsimonious reductions, but
for a 3D space that was indeed possible. Moreover, Hollender et al.
\cite{hollender_ComplexityMultisourceVariants_2018} demonstated that known source variants
of the problem do not affect its \textbf{PPAD}-completeness. We therefore make the following conjecture:

\begin{conjecturebox}{\textit{nD-CountingSS} and \textit{Unbalanced}}{}
Does there exist some polynomial computable function $f :\mathbb{N}^3 \to \mathbb{N}$, such that
given $\alpha,\Delta_i, \Delta_o \in \mathbb{N}$ and $m= f(\alpha, \Delta_i, \Delta_o)$
$$
\textbf{PPAD}(\alpha\textit{-SUnbalanced}(\Delta_i, \Delta_o)) \subseteq
\textbf{PPAD}(m\textit{D-CountingSS}) 
$$
\end{conjecturebox}
What the above conjecture essentially describes is, given a number of known sources and the
maximum number of input/output vertices of graph, can we create some \textit{nD-CountingSS}
that is parsimonious? This would allow us to bridge graph representations with topological representations
and hopefully allow us to get closer to a \textit{PureCircuit} total reduction.
