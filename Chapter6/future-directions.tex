
\subsection{Theory Directions}


\subsubsection{\textbf{HF-PPAD} in  \textbf{PPAD}}

In section \ref{sec:pc-plus-eol}, we expanded on
how Kleene logic can be incorporated with \textbf{PPAD} problems. For
the \textit{nD-StrongSperner} problems we observed that \textit{Kleene logic}
provides a natural extension and is equivalent to its non hazard counterpart.
For other problems such as \textit{StrongSperner}, we observed that this
is not clear by current complexity assumptions and indeed proving \textbf{PPAD}-hardness
would be essential for establishing the counting hardness of \textit{PureCircuit}.
However futher questions arise such as could we define
complexity classes for instance \textbf{HF-PPAD} and could we show that
$\textbf{HF-PPAD} = \textbf{PPAD}$.
Similarly, we can also question the existence of problems
\textit{HF-nD-Counting-SS} as previously stated and whether there
exists a parsimonious reduction to its non-hazard-free variant.


Naturally, one can also ask, how does hazard-freeness
affect \textbf{TFNP} as a whole? We conjecture that one can make
similar observations to the \textit{StrongTucker} problem \cite{aisenberg_2DTuckerPPA_2020},
in order to create similar classes such as \textbf{HF-PPA}, as
it also employs a similar colouring protocol to \textit{StrongSperner}.
Moreover, we were able to observe how we can use Kleene logic with
\textbf{PLS} sub-problems like \textit{Tarski}. Naturally,
one could extend the hazard-freeness property to the entire \textbf{TFNP} class,
and investigate its relations with the non-hazard variant. We believe that this shift
in perspective may also give insights to other areas such as the circuit complexity of \textit{Hazard-Free circuits}.


\subsubsection{Parsimonious Topological Representations of \textbf{PPAD} problems}

We summarise our conclusion from section \ref{sec:sc-excess}, by conjecturing
the existence of a parsimonious reduction from an \textit{nD-Counting-SS} to a
\textit{Counting-SS} problem as it would demonstrate an important stepping
stone towards its parsimonious reduction to the \textit{PureCircuit} problem.
Moreover, given our \textbf{PPAD} hierarchies, we can create the following conjecture  \ref{conj:conj-counting-ss-unb}
which combines the graph representations with the topological ones.


\begin{conjecturebox}{\textit{nD-CountingSS} and \textit{Unbalanced}}{conj-counting-ss-unb}
    There exist some polynomial computable function $f :\mathbb{N}^3 \to \mathbb{N}$, such that
    given $\alpha,\Delta_i, \Delta_o \in \mathbb{N}$ and $m= f(\alpha, \Delta_i, \Delta_o)$
    $$
        \textbf{\#PPAD}(\alpha\textit{-SUnbalanced}(\Delta_i, \Delta_o)) \subseteq
        \textbf{\#PPAD}(m\textit{D-CountingSS})
    $$
\end{conjecturebox}
The above conjecture describes the potential relations between the number of known sources and the
maximum number of input/output vertices of graph with topological problems
such as \textit{nD-CountingSS}. Since we know that the problem \textit{Unbalanced}
can parsimoniously count every graph variant, we conjecture the existence of a topological representation
of the \textit{Unbalanced} problem. A reduction like that would be an important milestone for the usage of topological \textit{PureCircuit} constructions
for enumerating solutions.


\subsubsection{PureCircuit Gate Extension} 

The proof for the \textbf{PPAD}-inclusion can be summarised by expressing a \textit{PureCircuit} instance
as a \textit{Brouwer} function from $[0,1]^n \to [0,1]^n$, where
each input represents a continuous assignment to the circuit nodes,
and each output $F_i(x)$ is determined by a continuous function of the gate incident to node $i$ and its neighbouring nodes
\cite{deligkas_PureCircuitTightInapproximability_2024}.
Given its fixed point $x^\star$
we can then denote the following assignment: if $x^\star_i \in \{0,1\}$ then $v_i = x^{\star}_i$, otherwise
$v_i = \bot$. For example, the \textsc{Purify} gate can be represented as:
$$
\textsc{Purify}(v) = \begin{pmatrix}
    \max\{2v_1 -1 , 0\} \\
    \min\{2v_2, 1\} \\
\end{pmatrix}
$$
Deligkas et al. \cite{deligkas_PureCircuitTightInapproximability_2024} 
showed that as long as our gate set consists of the \textsc{Purify} gate and \textsc{NOR} or \textsc{NAND}
or any combination of gates that are functionally complete with respect to boolean logic,
\textit{PureCircuit}  is \textbf{PPAD}-complete.
This implies that we can extend the gate set of \textit{PureCircuit} to any gate that exhibits
continuity behaviour under $[0,1]$ since we could always use the \textit{Brouwer} problem
to find a solution. We argue that there may exist gates that have 
a more intricate combinatorial nature and therefore assist in the resolution of our conjectures.

\subsubsection{PureCircuit with ATMs}
\label{sub-sub-sec:fw:pc-atms}

In our supplementary finding section \ref{sec:chap-3:supp-findings},
we showed how to relate variants of the \textit{Tarski} problem
with \textit{PureCircuit}. We also know that based on
\textit{Tarski}'s theorem, we can always find a labelling function
on ATMs which demonstrates whether our starting configuration is accepting, rejecting or non-halting.
This relation may provide a path towards the full Cook-levin type theorem
that we seek. However, one also has to acknowledge the difficulty of expressing
operator functions such as $\tau$, as it seeks
to find the maximal element in the poset of functions of $\mathcal{C} \to \mathbb{T}$,
whereas our reduction was based on the poset of the information ordering of Kleene logic. We leave this as integral evidence
for the potential relation between \textit{PureCircuit} and ATMs.


\subsection{Software future Directions}

Given the algorithms that we proposed for our software, we argue that there are several improvements
that can be made.
For all three algorithmic methods mentioned, the most prominent extension
is to treat weakly directly connected components individually. Trivially an assignment in a
weakly connected component should not affect the solution set of the other one.
We can therefore reduce the search spaces of our problems by finding
the solution sets in each graph separately. Moreover, for the
\textit{backtracking} algorithm, we can extend the above notion by considering
the Cartesian product of the solution sets, meaning:
$$
    \textbf{sol}(G) = \bigtimes_{i \in [k]}  \textbf{sol}(G_i)
$$
Where $G_i$ is the $i$th connected component.

We can also optimise the backtracking algorithm even further.
First one can observe that if our graph was acyclic, then
the set of the nodes with no \textit{in-degree} solutions have a significant
influence to the downstream nodes. Consequently, we can apply any of the 
extensions to convert our instances into DAGs:
\begin{enumerate}
    \item Apply an arbitrary DFS algorithm such that we annotate each node with the length of its DFS path.
    \item Identify the strongly connected components (SCCs) of the circuit, using polynomial
          time algorithms such as Kosaraju's Algorithm \cite{sharir_StrongconnectivityAlgorithmIts_1981} 
          or Gabow's Algorithm \cite{gabow_PathbasedDepthfirstSearch_2000}, in order
          to create a directed acyclic hypergraphs. Associate nodes in SCCs
          with the topological sort of the hypergraphs. 
\end{enumerate}

We argue that the above heuristics may result in improved average times, but
further research is required in order to determine more suitable selection heuristics for our priority queue.

Lastly, we highlight potential improvements to our meta-heuristic algorithms. 
The fitness function could be modified to take advantage of the continuity properties of the \textit{PureCircuit}, 
and each algorithm can be improved using more sophisticated techniques. 
More broadly, one could explore additional meta-heuristic approaches 
beyond those considered here, as shown in the survey\cite{abdel-basset_Chapter10Metaheuristic_2018}.
